# getportside.com

Source of [getportside.com](https://getportside.com) — the home of
**Portside**, a keyboard-first, two-pane file manager for macOS with a real
built-in terminal.

The site is plain HTML/CSS: no build step, no JavaScript, no third-party
requests. This repository also serves Portside's release downloads and its
update feed.
