# getportside.com

Source of [getportside.com](https://getportside.com) — the home of
**Portside**, a keyboard-first, two-pane file manager for macOS with a real
built-in terminal.

The site is plain HTML and CSS with no build step, plus Paddle’s `Paddle.js`
checkout script on the landing page. This repository also serves Portside’s
release downloads and its Sparkle update feed.
